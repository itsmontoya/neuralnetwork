## Summary
- Add a deterministic, checksummed binary model format while retaining the existing JSON contract.

## Changes
- Stream versioned little-endian architecture and raw float32 parameter records through io.Reader and io.Writer.
- Verify a SHA-256 content checksum and expose it for sidecar manifests.
- Bound layer, activation-width, string, and cumulative matrix sizes before proportional allocation.
- Round-trip every supported layer and preserve prediction parity and evaluation parameters.
- Reject truncated, corrupt, trailing, oversized, malformed, unknown-layer, and unknown-version artifacts.
- Document the byte contract, compatibility policy, decoder limits, and JSON comparison.
