## Changed files and API

`tensor/concat.go` and `tensor/gather.go` implement the exact contracted APIs:

```go
func ConcatShape(inputs [][]int64, axis int64) (shape []int64, err error)
func GatherShape(data, indices []int64, axis int64) (shape []int64, err error)
func ConcatInto(inputs []*Tensor, destination *Tensor, axis int64) (err error)
func GatherInto(data, indices, destination *Tensor, axis int64) (err error)
```

## Ownership and supported cases

Both operations copy float32 or int64 data into exact-shape/type caller-owned
destinations. Integer values never pass through floats; copies preserve float32
bits. No backing slices, borrowed values, or metadata aliases escape. Shape
planners return independent metadata without allocating numeric payloads and
check int64 payload bounds so output shapes support either data type.

Concat requires a nonempty list with equal type/rank and non-axis dimensions.
Its normalized axis sum is checked even if another dimension is zero. Repeated
read-only inputs and zero-length axis contributions are supported. Scalars
have no concatenation axis.

Gather accepts positive-rank data and int64 indices. Its output shape is the
data prefix, complete indices shape, and data suffix. Scalar, multidimensional,
repeated, negative, and empty indices work. Bounds are checked against the
selected data dimension before negative-index addition, including int64 extrema.
Every index is checked before writes even if an unrelated dimension makes the
output empty. A zero-length data axis accepts only empty indices. Shape-only
planning cannot validate index values; `GatherInto` performs that validation.

Both kernels validate all inputs/destinations, types, axes/shapes, storage
identities, and required block geometry before writes. Pointer and shallow-copy
destination aliases are rejected, including empties and Gather's indices input.
Input/input aliases are read-only and allowed. Returned errors preserve the
destination. Nonempty copies use contiguous blocks; loop offsets and host-int
conversions are bounded by checked geometry and validated payload lengths.
Empty results skip unused products only after all validation, including indices.

Private `concatBlockSizes`/`concatBlocksInto` and
`gatherBlockSizes`/`gatherBlocksInto` are operation-local geometry/copy helpers;
their unchecked loops require the validated nonempty caller path. Future
kernels should reuse existing shared `checkedAdd`, `checkedMultiply`,
`checkedProduct`, `NormalizeAxis`, `ValidateShape`, `validateTensorType`, and
`validateDestination`, rather than duplicating size or alias rules.

Inputs remain unchanged. Outputs survive subsequent calls with different inputs.
Concurrent callers may share immutable data/indices with disjoint destinations;
all metadata scratch belongs to a call. No workspace, retained output, hidden
global state, optimizer parameter, or backward cache is introduced.
